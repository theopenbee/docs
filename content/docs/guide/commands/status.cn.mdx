显示当前会话的快照：哪些 Bee 处于活跃状态，以及哪些即时任务正在运行。

## 语法

```text
/status     # 显示当前会话中活跃的 Bee 及正在运行的任务
```

`/status` 不接受任何参数。

## 输出格式

```text
当前会话状态：
已激活 bee（2）：
  - DocBot   引擎: claude   最近活跃: 3m 前
  - CodeBot   引擎: codex   最近活跃: 12s 前
进行中任务（1）：
  - DocBot 生成 API 参考文档…   已运行 5m   exec: a1b2c3d4
```

### 已激活 Bee

**已激活 bee** 部分的每一行包含：

| 字段 | 说明 |
|------|------|
| 名称 | 数字员工名称 |
| `引擎` | 该数字员工当前使用的 AI 引擎 |
| `最近活跃` | 距离该数字员工最后一次更新状态的时间 |

### 进行中任务

**进行中任务** 部分的每一行包含：

| 字段 | 说明 |
|------|------|
| 名称 | 任务所属的数字员工名称 |
| 指令 | 任务指令的前 40 个字符（空白符已规范化） |
| `已运行` | 任务从开始到现在的运行时长 |
| `exec` | 执行 ID 的前 8 位（可用于在服务端日志中定位任务） |

此处只显示**即时任务**（在聊天中直接触发的任务），定时或后台任务不在列表中。

### 时间格式

时间使用简洁记法：

| 时长 | 格式 | 示例 |
|------|------|------|
| 0–59 秒 | `Xs` | `30s` |
| 1–59 分钟 | `Xm` | `5m` |
| 1–23 小时 | `Xh` | `12h` |
| 24 小时及以上 | `Xd` | `2d` |

### 空状态

如果没有活跃的 Bee 或没有正在运行的任务，对应部分仍会显示，但内容为 `（无）`：

```text
当前会话状态：
已激活 bee（0）：
  （无）
进行中任务（0）：
  （无）
```

## 错误响应

| 情况 | 提示信息 |
|------|----------|
| 无法查询会话或任务状态 | `⚠️ 查询会话状态失败，请重试；如果问题持续，请检查服务端日志。` |

## 什么时候用 `/status`

- **确认 Bee 是否在运行**，再决定是否发送后续消息。
- **查看当前有哪些任务在飞**，在执行 `/stop` 或 `/clear` 前先摸清情况。
- **定位卡住的任务** — 如果某个任务运行时间异常长，可以用 `exec` ID 在服务端日志中追查。
- **快速健康检查** — 感觉哪里不对但不确定原因时，用 `/status` 先看看现状。
