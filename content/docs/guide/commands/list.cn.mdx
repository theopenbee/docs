---
title: /list
description: 列出所有数字员工，可通过关键词过滤
---

显示 OpenBee 部署中所有已注册的数字员工。可选关键词参数可以将结果缩小到描述中包含该词的员工。

## 语法

```text
/list                   # 列出所有数字员工
/list {关键词}           # 列出描述中包含关键词的数字员工
```

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| `关键词` | 否 | 对员工描述进行不区分大小写的子字符串匹配。 |

## 示例

列出所有数字员工：

```text
/list
```

返回：

```text
员工列表（共 3 个）：
  - CodeBot   状态: 工作中   openbee 后端全栈工程师
  - DocBot   状态: 空闲   openbee 文档团队技术写手
  - QABot   状态: 空闲   专注于 openbee 测试覆盖的 QA 工程师
```

按关键词过滤：

```text
/list openbee
```

返回：

```text
匹配 "openbee" 的员工（共 3 个）：
  - CodeBot   状态: 工作中   openbee 后端全栈工程师
  - DocBot   状态: 空闲   openbee 文档团队技术写手
  - QABot   状态: 空闲   专注于 openbee 测试覆盖的 QA 工程师
```

无匹配：

```text
/list xyz
```

返回：

```text
匹配 "xyz" 的员工（共 0 个）：
  （无匹配的员工）
```

## 输出说明

每行员工信息包含：

| 字段 | 说明 |
|------|------|
| 名称 | 数字员工名称 |
| `状态` | 当前员工状态 |
| 描述 | 员工描述文本 |

### 员工状态标签

| 状态 | 标签 |
|------|------|
| 空闲 | `空闲` |
| 工作中 | `工作中` |
| 异常 | `异常` |

### 过滤行为

- 关键词只匹配**描述字段**，不匹配员工名称。
- 匹配**不区分大小写**，且为**子字符串匹配** — 关键词不需要是完整的单词。
- 结果按**员工名称字母顺序**排列，无论是否有过滤条件。

### 空状态

| 情况 | 输出 |
|------|------|
| 没有任何员工 | `员工列表（共 0 个）：` 然后 `（暂无员工）` |
| 过滤后无匹配 | `匹配 "xyz" 的员工（共 0 个）：` 然后 `（无匹配的员工）` |

## 错误响应

| 情况 | 提示信息 |
|------|----------|
| 数据库查询失败 | `⚠️ 员工列表查询失败，请重试；如果问题持续，请检查服务端日志。` |

## 什么时候用 `/list`

- **了解有哪些数字员工可用**，再决定把任务交给谁。
- **通过描述关键词找到某个员工** — 记不住确切名字时很有用。
- **快速查看员工状态** — 一眼看出哪些员工空闲、哪些正在忙。
